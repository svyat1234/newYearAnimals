# 🎄 Новогодний проект "Праздники без опасности"

## 📖 Общее описание
Интерактивный сайт-игра для Фонда защиты городских животных. Пользователи проходят 9 вопросов о безопасности животных в новогодние праздники, нажимая на цифры на интерактивной карте.

## 🛠 Технологии
- **React** - JavaScript библиотека для создания интерфейса
- **Vite** - сборщик и dev-сервер
- **CSS** - стили с CSS-переменными и адаптивной версткой
- **Service Worker** - кеширование и работа оффлайн

## 🧩 Компоненты (src/components/)

### 🎲 **GameBoard.jsx** - Главный игровой экран
**Что делает:** Объединяет все слои игры и управляет модальными окнами
**Важно:** Содержит состояние открытых вопросов и счетчик пройденных тестов

### 🏔 **Слои (layers/)** - Визуальные слои игры

#### **BackgroundLayer.jsx**
- **Что:** Фоновое изображение
- **Логика:** Переключает фон для мобильной/десктопной версии

#### **MiddlegroundLayer.jsx** 
- **Что:** Персонажи, деревья, объекты на карте
- **Логика:** Рендерит спрайты из `src/data/sprites.js` с адаптивными координатами

#### **InteractiveLayer.jsx**
- **Что:** Кликабельные цифры 1-9
- **Логика:** При клике открывает соответствующую модалку с вопросом

#### **SnowLayer.jsx**
- **Что:** Снежный эффект поверх всего

### 🖼 **Оптимизация изображений**

#### **QueuedImage.jsx**
- **Что:** Обертка для оптимизированной загрузки изображений
- **Логика:** Использует `LazySvg` для ленивой загрузки

#### **LazySvg.jsx** 
- **Что:** Ленивая загрузка изображений
- **Логика:** Загружает изображения только когда они почти видны пользователю (за 200-300px)

### 💬 **Модальные окна (modals/)**

#### **ModalSystem.jsx**
- **Что:** Управляет всеми модальными окнами
- **Логика:** Хранит состояние пройденных вопросов, блокирует скролл при открытии модалки

#### **QuestionModal.jsx**
- **Что:** Модалка с вопросом теста
- **Логика:** Управляет выбором ответа, показом пояснений, сменой кнопок "Ответить"→"Продолжить"

#### **CompletionModal.jsx**
- **Что:** Модалка с результатами после прохождения тестов
- **Логика:** Показывает табы, результат, разные цвета крестика

### 🎨 **UI компоненты (ui/)**

#### **UILayer.jsx**
- **Что:** Интерфейс поверх игры (header, footer, счетчик)
- **Логика:** Плавное появление подсказки при скролле, показ счетчика пройденных тестов

## 🎨 Стилизация

### **CSS Переменные** (src/index.css)
```css
:root {
  --vw1920: calc(100vw / 1920);  /* 1 единица = 1px при ширине 1920px */
  --vw320: calc(100vw / 320);    /* 1 единица = 1px при ширине 320px */
  --vw: var(--vw1920);          /* Используется по умолчанию */
}

@media (max-width: 1024px) {
  :root {
    --vw: var(--vw320);         /* На мобильных переключается */
  }
}
```

### **Адаптивная верстка**
- **Десктоп макет:** 1920×5541px
- **Мобильный макет:** 320×3172px
- **Брейкпоинт:** 1024px

**Формулы координат:**
```javascript
// Десктоп
top: calc(значение / 5541 * 100%)
left: calc(значение / 1920 * 100%)

// Мобайл  
top: calc(значение / 3172 * 100%)
left: calc(значение / 320 * 100%)
```

## ⚙️ Логика работы

### **🎯 Основной игровой флоу:**
1. Пользователь видит интерактивную карту
2. Нажимает на цифру (1-9) 
3. Открывается модалка с вопросом
4. Выбирает ответ → нажимает "Ответить"
5. Появляются пояснения с правильным/неправильным ответом
6. Нажимает "Продолжить" → модалка закрывается
7. В правом нижнем углу появляется счетчик пройденных тестов
8. После всех тестов показывается модалка с результатами

### **📱 Адаптивность:**
- Автоматическое определение мобильного устройства
- Разные координаты и размеры для мобильной версии
- Отдельные изображения для мобильных устройств

### **⚡ Оптимизация:**
- **Ленивая загрузка изображений** - загружаются за 200-300px до видимости
- **Очередь загрузки** - максимум 6 изображений одновременно
- **Service Worker** - кеширование для работы оффлайн
- **CSS переменные** - единая система масштабирования

## 📝 Как редактировать контент

### **🖼 Добавить/изменить спрайт на карте:**
1. Добавить изображение в `src/assets/images/`
2. Обновить `src/data/sprites.js`:
```javascript
{ 
  id: 'новый-спрайт',
  src: img('новый-спрайт.svg'),
  top: 1234,     // Координаты из макета
  left: 567,
  width: 200,
  z: 10,
  mobile: {      // Мобильные координаты (опционально)
    top: 800,
    left: 50,
    width: 100
  }
}
```

### **🎯 Добавить/изменить кнопку:**
1. Обновить `src/data/gameConfig.js`:
```javascript
{ 
  id: 10,           // Номер кнопки
  top: 2000,        // Координаты
  left: 500,
  variant: 'default',
  label: '10',
  mobile: { top: 1200, left: 160 }
}
```

### **❓ Изменить вопрос:**
1. Редактировать `src/data/modals/questions.js`
2. Изменить `title`, `text`, `choices` нужного вопроса
3. Добавить изображение в `src/assets/images/modals/`

### **🏆 Изменить результаты:**
1. Редактировать `src/data/modals/results.js`
2. Изменить `title`, `description` в `completionData`
3. Обновить тексты в `completionTabs`

## 🎨 Настройка стилей

### **CSS Переменные**
Используйте `calc(var(--vw) * значение)` для адаптивных размеров:
```css
font-size: calc(var(--vw) * 24);    /* 24px при ширине макета */
width: calc(var(--vw) * 300);       /* 300px при ширине макета */
```

### **Мобильная адаптация**
```css
@media (max-width: 1024px) {
  .element {
    font-size: calc(var(--vw) * 16);  /* Другой размер на мобильных */
  }
}
```

## 🚀 Деплой и PWA

### **Service Worker** (`public/sw.js`)
- Автоматически кеширует ресурсы
- Обеспечивает работу оффлайн
- Версия кеша: обновите `CACHE_NAME` при изменениях

### **PWA Функции**
- Можно установить как приложение на устройство
- Работает без интернета после первого посещения
- Настройки в `public/manifest.webmanifest`

### **Оптимизация изображений**
- SVG файлы для качества на всех экранах
- Ленивая загрузка с предзагрузкой за 200-300px
- Автоматическое управление очередью загрузки

## 🔍 Отладка и разработка

### **Режим разработки:**
- Service Worker отключен (избегаем проблем с кешем)
- Hot reload - изменения видны сразу
- React DevTools для отладки компонентов

### **Консоль браузера:**
- Intersection Observer логи (для отладки анимаций)
- Ошибки загрузки изображений
- Состояние модальных окон

### **Проверка PWA:**
- Откройте DevTools → Application → Service Workers
- Проверьте кеш в Application → Cache Storage
- Тестируйте оффлайн режим: DevTools → Network → Offline
